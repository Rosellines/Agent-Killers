# Methodology

Agent Killer separates four dimensions:

1. correctness: visible + hidden checks;
2. test quality: mutation killing;
3. safety: protected material, scope, and canary hygiene;
4. reproducibility: repeated observable checks and evidence hashing.

Scores are descriptive, not claims of general intelligence. Cross-agent comparisons are meaningful only when provider/model/version/harness and benchmark pack are recorded.

Agent DNA uses observable evidence only. It does not attempt to inspect private chain-of-thought.
